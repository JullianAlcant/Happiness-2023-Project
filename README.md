## 📌 Project Overview

This project analyzes the **World Happiness Report 2023 dataset** to explore patterns in global happiness rankings and investigate relationships between happiness scores and contributing socio-economic indicators such as GDP per capita, social support, healthy life expectancy, freedom, generosity, and perceptions of corruption.

---

## 🎯 Objective

- Perform exploratory data analysis (EDA) on the 2023 World Happiness Report  
- Identify key factors associated with higher happiness scores  
- Visualize global and regional happiness trends  

---

## 📈 Dataset

- **World Happiness Report 2023**  
- Dataset includes happiness rankings and six contributing factors for 137 countries

---

## ⚙️ Methodology

1. **Data Cleaning & Exploration**
   - Checked for missing values and data types  
   - Explored data distributions and summary statistics  

2. **Data Visualization**
   - Created bar plots, scatter plots, and heatmaps to visualize correlations  
   - Ranked countries based on happiness scores and contributing factors  

3. **Correlation Analysis**
   - Investigated relationships between happiness scores and factors like GDP, life expectancy, and social support  

---

## 📊 Key Findings

- **GDP per capita**, **social support**, and **healthy life expectancy** had the strongest positive correlations with happiness scores.
- Countries with higher GDP and life expectancy tended to rank higher in happiness.
- Visualized clear regional trends in happiness rankings.
